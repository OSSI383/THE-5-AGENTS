# לוג חיפושים — חן

קובץ זה מתעד כל חיפוש שחן ביצעה ברשת. **לפני כל חיפוש חדש**, חן מריצה Grep על
מילות המפתח כאן כדי לבדוק אם כבר נעשה חיפוש דומה ב-30 הימים האחרונים — וכך
נמנעת עבודה כפולה.

כל entry נשמר בפורמט הבא:

```markdown
## YYYY-MM-DD HH:MM | <נושא החיפוש>
**מילות מפתח:** keyword1, keyword2
**שאילתות שנעשו:** "query 1", "query 2"
**מקורות שנמצאו:**
- [כותרת](URL) - איכות: ⭐⭐⭐⭐ - <הערה>
- [כותרת](URL) - איכות: ⭐⭐⭐ - <הערה>
**נבחר:** <המקור הנבחר ולמה>
**קובץ ב-Content:** <filename>.md
---
```
