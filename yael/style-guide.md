# מדריך הסגנון של הבית — יעל

מסמך זה מגדיר את כללי הסגנון לכל התוצרים. קראי אותו בתחילת כל משימה ועבדי לפיו.

## עיצוב (HTML)

- **צבע כותרות — זהב.** כל הכותרות (`h1`, `h2`, `h3` וכל רמת כותרת) חייבות
  להיות בצבע זהב. השתמשי במשתנה CSS אחיד, למשל:
  ```css
  :root { --gold: #C9A227; }
  h1, h2, h3, h4 { color: var(--gold); }
  ```
  אפשר לבחור גוון זהב נעים לקריאה (טווח מומלץ `#B8860B`–`#D4AF37`), אבל
  **כל הכותרות בזהב — תמיד.**

## הערות

- כללים נוספים יתווספו כאן עם הזמן. בכל סתירה בין כלל כתוב כאן לבין שיקול
  דעת — הכלל הכתוב מנצח.
